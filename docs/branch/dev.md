# 'dev' branch
The dev branch is the branch dedicated solely to developement of the program.

In here is where all of the changes and bugfixes get commited to. The commits done to this branch can include:
- New features merged into 'dev' (see *docs/branch/feat.md*)
- Bug fixes
- Hotfixes (see *docs/branch/hotfix.md*)
- Commits by contributors (tysm for that btw)

For adding features to the program by contributing, all changes MUST be commited to the 'dev' branch specifically (with a pull request). Later, when ready for release, a new release branch will be made off of 'dev' (see *docs/branch/release.md*), bug fixes and testing will be done, and once ready, the branch will be merged into main (see *docs/release_structure.md)
