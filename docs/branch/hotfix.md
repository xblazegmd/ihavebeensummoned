# Hotfix branches
Oh no! There's this very bad bug we need to fix! I guess we need to do a hotfix...

Hotfix branches are usually reserved for very critical bugs in the program (e.g. security issues, program's not working, etc).
Once the issue's fixed, the hotfix branch will be merged into 'dev' (see *docs/branch/dev*) and 'main' (as well as a new hotfix update).

You know you found a hotfix branch when the branch is called 'hotfix/*'

Hotfix branches are only meant to be used by me or people assigned to that hotfix. You should not commit any changes to it unless it helps fix the issue that's getting fixed.
